#  Crear un proyecto de FastAPI

## 1. Configuración del Entorno 

Para crear un proyecto de fastAPI, necesitaremos instalarlo dentro de un entorno virtual.

Python nos permite aislar instalaciones (dependencias) dentro de un directorio (carpeta), para que sean usados únicamente por los proyectos contenidos en la misma.

### Preparación del Proyecto

1. **Crear entorno virtual:**
```bash
python3 -m venv venv
```
> El segundo venv corresponde al nombre que se le da al entorno virtual. Comúnmente se lo llama "venv" o "env".


2. **Activar el entorno:**

Una vez creado el entorno virtual, tendremos que activarlo desde nuestra consola. Lo hacemos con el siguiente comando:

* **Linux / Mac:**
```bash
source venv/bin/activate

```


* **Windows:**
```powershell
.\venv\Scripts\activate

```

> Si estuvieran usando una consola de linux en windows (como lo puede ser git bash), tendrían que usar un comando como `source venv/Scripts/activate`



3. **Instalación de dependencias:**
* (Solo si es necesario en Linux) Instalar pip: `sudo apt install python3-pip` 


* Verificar paquetes instalados: `pip list` 

> De haber salido todo bien, la pip list mostraría una lista sin instalaciones.

* **Instalar FastAPI (versión estándar):**
Una vez que estamos dentro del entorno virtual, ya podemos instalar los paquetes de FastAPI.

```bash
pip install fastapi[standard]

```

> De ocurrir algun inconveniente, intentar con `pip install fastapi"[standard]"`

## 2. Primeros Pasos: Hola Mundo


**Archivo: `app.py`**

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def home():
    return {"Hola":"Mundo"}

```

> Asegúrense que app.py esté al mismo nivel que venv. Es decir, app.py no debe estar ni adentro de la carpeta de venv ni afuera de la carpeta donde está contenido venv.

> app.py también puede ser llamado main.py
